# Картинки предметов на карте

Положи сюда PNG с прозрачным фоном под одним из имён ниже и пересобери игру. Файл заменит картинку, которую игра рисует сама (`src/propArt.ts`).
Размер файла: в 3–4 раза больше указанного, с теми же пропорциями.

Вид: **сверху-сбоку** (как деревья и герой). Исключение — машины: они **строго сверху**, нос смотрит вправо (игра сама их поворачивает).
