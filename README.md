# MyZombika

Прототип бродилки-стрелялки с видом сверху: зомби и другие монстры наступают волнами.
Графика окружения и герой взяты из LLM Survival. Герой и зомби собраны из срезов (псевдо-3D, sprite stacking, `src/heroStack.ts`), зомби — та же модель, перекрашенная.

## Запуск
**Просто играть:** двойной клик по `MyZombika.html`. Node и сервер не нужны, всё (код и картинки) внутри одного файла. Этот файл можно скинуть на телефон и открыть в браузере.

**Разработка:** нужен Node.js 20+. `Запустить.cmd` (или `npm install`, потом `npm run dev`), откроется http://localhost:5174 и будет обновляться при правке кода. С телефона в той же Wi-Fi сети: `http://<IP компьютера>:5174`.
После правок пересобрать `MyZombika.html`: `npm run build` и скопировать `dist/MyZombika.html` в корень.

## Управление
- Клавиатура и мышь: WASD или стрелки — ходить, мышь — прицел (красная линия), ЛКМ (можно держать) — стрелять, R — перезарядка, M — звук, Esc или P — пауза.
- Тачскрин: левая половина экрана — стик ходьбы, правая половина — стик прицела; потянул дальше — стреляет.
- Тачскрин: кнопка паузы в правом верхнем углу.
- После смерти: клик, касание или пробел — заново.

## Свет и время суток
Сутки длятся 4 минуты (`DAY_LEN` в `src/light.ts`). Днём деревья, камни, зомби и герой отбрасывают тени от солнца: утром влево, в полдень коротко вниз, вечером длинные вправо. Ночью темно, светит только фонарь героя: пятно вокруг и луч по прицелу. Стволы, камни и враги отбрасывают от него настоящие тени, у зомби светятся глаза.
Начать в нужное время: `?time=day`, `?time=evening`, `?time=night` или число 0..1 (0 — рассвет, 0.25 — полдень, 0.5 — закат, 0.75 — полночь).

Пули рикошетят от камней (до двух раз) и застревают в деревьях.

## Где что
- `src/main.ts` — вся игра: мир, герой, оружие, враги, волны, HUD, стики.
- `src/light.ts` — день/ночь, тени, фонарь.
- `src/sfx.ts` — все звуки (синтез, без файлов).
- `src/heroStack.ts` — воксельная модель героя и палитры (герой, два вида зомби).
- `src/sprites/` — картинки из LLM Survival (при сборке встраиваются в html).
- `?wave=5` в адресе — начать с пятой волны.

## Кооператив по сети (до 4 игроков)
- Хозяин: Esc → «Позвать друга» (или клавиша H). Вверху появится код из 5 знаков.
- Друг: Esc → «Войти по коду» (или J) и вводит код. На сайте можно просто открыть ссылку `?join=КОД`.
- Соединение напрямую между браузерами (WebRTC через бесплатный сервер знакомств PeerJS), своего сервера не нужно.
- Монстров, волны и попадания считает хозяин. Выбывший оживает в начале следующей волны, игра кончается, когда выбыли все.
- Для проверки на своём сервере знакомств: `?broker=127.0.0.1:9000`.

## Гранаты и аптечки
- Иногда выпадают с монстров (с медведя почти всегда). Подбираются, если подойти.
- Бросок: G или правая кнопка мыши (на тачскрине — кнопка над правым стиком).
